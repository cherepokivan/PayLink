# PayLink — Android Application

Быстрое выставление счетов и передача платёжных ссылок для Android-устройств.

## Возможности
- **Платёжные методы**: ЮMoney и СБП (Система быстрых платежей).
- **Справочник банков СБП**: Т-Банк, СберБанк, ВТБ, Альфа-Банк, Газпромбанк, ПСБ, Россельхозбанк, Райффайзен, Совкомбанк, Ozon Банк, Яндекс Банк и др. с поиском.
- **Динамический QR-код**: мгновенно генерирует QR-код с URL оплаты при изменении суммы или комментария.
- **NFC передача (NDEF)**: передача платёжной ссылки через Host-based Card Emulation (HCE Type 4 Tag). Второй телефон считывает NFC-метку и открывает страницу оплаты.
- **Безопасность**: приложение не считывает банковские карты, не запрашивает PIN/CVV и не выполняет списание средств.
- **Хранение настроек**: DataStore Preferences.
- **Дизайн**: Material 3, адаптивная верстка, поддержка светлой и тёмной темы, динамические цвета Material You, кастомная иконка.

## Стек технологий
- Kotlin, Coroutines, StateFlow
- Jetpack Compose, Material 3
- DataStore Preferences
- ZXing (генерация QR-кода)
- Android NFC (HCE Type 4 Tag, NDEF URI)
- Clean Architecture (MVVM, Repository & Provider patterns)
